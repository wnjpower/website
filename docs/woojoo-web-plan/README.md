## 0. 이 개편의 목적

기존 전기공사업체 홈페이지는 대부분 **"회사 소개 브로슈어"** 입니다. 이 개편의 목적은 다음 두 가지입니다.

1. **고객 유형별 페이지 분리** (영국 UK Electrical 방식) — 방문자가 "나 같은 사람을 위한 페이지"에 즉시 도달
2. **AI 검색엔진 인용 대응** (GEO / AEO) — ChatGPT·Perplexity·Gemini·네이버 AI브리핑이 답변을 만들 때 우앤주전력을 근거로 인용하도록 설계

### AI 인용이 일어나는 조건 (설계 원칙)

| 조건 | 구현 방법 |
|---|---|
| 엔티티가 명확할 것 | JSON-LD `Electrician` + 전기공사업 등록번호·사업자번호 명시 |
| 질문-답변 쌍이 존재할 것 | FAQ 롱테일, 두괄식 3문장 이내 |
| 답변이 자기완결적일 것 | 각 문단이 앞뒤 맥락 없이 인용 가능하도록 작성 |
| 맥락(누가·어디서·언제)이 붙어있을 것 | "대구에서 카페를 창업하는 경우" 식 상황 수식어 |
| 수치·법규 근거가 있을 것 | 전기공사업법 조항, KEC, 계약전력 구간, 소요 기간 |
| 크롤링이 가능할 것 | SSR/정적 HTML, llms.txt, robots.txt AI봇 허용 |

**핵심: AI는 "일반론"을 인용하지 않습니다. "대구 서구에서 30kW 이하 상가 승압 시 통상 2~3주"처럼 조건이 붙은 문장을 인용합니다.**

## 2. 기술 스택 권장안

| 항목 | 권장 | 이유 |
|---|---|---|
| 프레임워크 | Next.js (App Router) + SSG/ISR | AI 크롤러 다수가 JS 실행 안 함 → **정적 HTML 필수** |
| 스타일 | Tailwind CSS | 유지보수 단순화 |
| 콘텐츠 | MDX 또는 JSON 데이터 파일 | 콘텐츠와 코드 분리, 스키마 자동 생성 |
| 배포 | Vercel | 이미 커넥터 연결됨 |
| 폼 | 서버 액션 + 이메일 발송 | 별도 백엔드 불필요 |

**절대 금지 사항**
- CSR 전용 렌더링 (AI 크롤러가 빈 페이지를 봄)
- 텍스트를 이미지로 처리 (시공 실적표, 자격 목록 등)
- 무한스크롤·탭 안에 핵심 콘텐츠 숨기기
- 팝업으로 초기 콘텐츠 가리기

## 4. 치환이 필요한 플레이스홀더

콘텐츠 전반에 아래 형식의 플레이스홀더가 있습니다. **실제 값 확인 후 일괄 치환하세요.**

| 플레이스홀더 | 설명 |
|---|---|
| `{{전기공사업_등록번호}}` | 대구광역시 등록번호 |
| `{{사업자등록번호}}` | 10자리 |
| `{{대표전화}}` | 대표번호 |
| `{{주소}}` | 대구 서구 상세 주소 |
| `{{설립연도}}` | 창업 연도 |
| `{{시공능력평가액}}` | 전기공사협회 공시 금액 |
| `{{기술자_보유현황}}` | 전기공사기사/산업기사 인원 |
| `{{도메인}}` | 최종 도메인 |

> **중요**: 확인되지 않은 수치는 절대 임의로 채우지 마세요. AI 인용 대응 사이트에서 허위 수치는 신뢰도 손실이 크고, 전기공사업법상 시공능력 허위표시는 행정처분 대상입니다. 값을 모르면 해당 섹션을 비워두고 TODO 주석으로 남기세요.
