# 03. AI 인용 최적화 기술 구현

## 1. 렌더링 — 가장 중요한 항목

AI 크롤러 상당수는 JavaScript를 실행하지 않거나 제한적으로만 실행합니다. **CSR로 렌더링되는 콘텐츠는 AI에게 존재하지 않는 것과 같습니다.**

### 필수 요구사항
- 모든 페이지 SSG 또는 SSR (Next.js `generateStaticParams` 활용)
- JSON-LD는 서버에서 HTML에 직접 삽입
- FAQ 답변은 `<details>/<summary>` 또는 항상 DOM에 존재하는 아코디언

### 검증 명령
```bash
# 각 주요 페이지에 대해 실행
for url in / /clients/interior/ /services/capacity-upgrade/ /faq/capacity/; do
  echo "=== $url ==="
  curl -s -A "GPTBot" "https://{{도메인}}$url" | grep -c "application/ld+json"
  curl -s -A "GPTBot" "https://{{도메인}}$url" | grep -o "요약" | head -1
done
```
JSON-LD 개수가 0이거나 본문 텍스트가 안 나오면 렌더링 방식을 고쳐야 합니다.

## 2. `robots.txt`

AI 크롤러를 **명시적으로 허용**하세요. 기본값으로 두면 일부 봇이 차단될 수 있습니다.

```
# public/robots.txt

User-agent: *
Allow: /
Disallow: /api/
Disallow: /*?type=
Disallow: /*?service=

# AI 검색·인용 크롤러 명시 허용
User-agent: GPTBot
Allow: /

User-agent: OAI-SearchBot
Allow: /

User-agent: ChatGPT-User
Allow: /

User-agent: ClaudeBot
Allow: /

User-agent: Claude-Web
Allow: /

User-agent: PerplexityBot
Allow: /

User-agent: Perplexity-User
Allow: /

User-agent: Google-Extended
Allow: /

User-agent: Applebot-Extended
Allow: /

User-agent: Yeti
Allow: /

Sitemap: https://{{도메인}}/sitemap.xml
```

> `Google-Extended`는 Gemini 학습·인용 관련, `Yeti`는 네이버 크롤러입니다.
> 학습 데이터 제공을 원하지 않으면 일부를 `Disallow`로 바꿀 수 있으나, **인용 노출을 목표로 한다면 허용이 맞습니다.**

## 4. 메타데이터 규칙

### Title
`{핵심 키워드} | {차별 요소} | 우앤주전력` (60자 이내)

- 좋은 예: `승압공사·계약전력 변경 | 신청부터 사용전점검까지 | 우앤주전력`
- 나쁜 예: `서비스 | 우앤주전력`

### Description
**FAQ 답변처럼 두괄식으로.** AI 스니펫에 그대로 쓰이는 경우가 많습니다. (150자 내외)

- 좋은 예: `대구 상가 승압은 통상 2~3주. 한국전력 계약전력 변경 신청 대행부터 분전반 공사, 사용전점검 대응까지 전기공사업 등록업체가 일괄 진행합니다.`

### Open Graph
모든 페이지에 `og:title`, `og:description`, `og:image`, `og:type`, `og:locale=ko_KR` 설정.

## 5. 시맨틱 HTML

AI는 HTML 구조로 정보의 계층을 파악합니다.

| 요소 | 규칙 |
|---|---|
| `<h1>` | 페이지당 1개 |
| `<h2>` | 자기완결적 섹션 단위 |
| `<table>` | 절차·기간·비교는 반드시 표로 (div 격자 금지) |
| `<dl>` | 용어 정의에 사용 |
| `<time datetime="">` | 게시일·수정일 |
| `<address>` | 회사 주소 |
| `<details>` | FAQ 아코디언 |

## 6. 콘텐츠 신선도

AI는 최신성을 중요하게 봅니다. 아래를 자동화하세요.

- 모든 페이지에 `dateModified` 표기 및 JSON-LD 반영
- 시공사례 월 2건 이상 추가
- FAQ 분기 1회 갱신
- 법규 관련 페이지 연 1회 검토 (개정 반영)

---

## 7. 배포 전 체크리스트

```
□ 모든 페이지가 curl로 텍스트·JSON-LD 확인됨 (CSR 아님)
□ Schema Validator 오류 0건
□ robots.txt에 AI 크롤러 명시 허용
□ llms.txt 배치 및 링크 정확성 확인
□ sitemap.xml 자동 생성, 네이버 서치어드바이저·구글 서치콘솔 제출
□ 모든 이미지 alt 텍스트 (검색어 형태)
□ 전화번호 tel: 링크, 모바일 하단 고정 CTA
□ Core Web Vitals — LCP 2.5초 이내
□ 모든 페이지 3방향 내부링크 (상위/횡단/하위) 적용
□ 플레이스홀더 {{ }} 전량 치환 완료
□ 법규 조문·수치 최신 여부 검증 완료 ← 필수
□ 시공능력평가액·실적 수치가 사실과 일치하는지 확인 ← 필수
□ NAP(상호·주소·전화) 사이트/네이버/구글 문자열 완전 일치
```

## 8. 개편 후 인용 여부 추적

월 1회, 아래 질문을 ChatGPT·Perplexity·Gemini·네이버 AI 브리핑에 입력하고 우앤주전력이 언급·인용되는지 기록하세요. 스프레드시트로 관리하면 개선 효과를 정량적으로 볼 수 있습니다.

| 유형 | 테스트 질문 |
|---|---|
| 지역+업종 | 대구 서구 전기공사업체 추천 |
| 절차 | 상가 계약전력 5kW에서 20kW로 올리는 절차 |
| 기간 | 카페 개업 전기 승압 얼마나 걸리나요 |
| 법규 | 전기공사 분리발주 의무인가요 |
| 비용 | 분전반 교체 비용 얼마 |
| B2B | 대구 전기공사 하도급 협력업체 |
| 공장 | 가동 중 공장 정전 없이 전기공사 가능한가요 |
| 자격 | 전기공사업 등록업체 확인 방법 |

**현실적 기대치**: 개편 직후에는 인용되지 않는 것이 정상입니다. AI가 새 콘텐츠를 인덱싱하고 신뢰하기까지 통상 3~6개월이 걸립니다. 처음에는 "전기공사업 등록업체 확인 방법"처럼 경쟁이 약하고 정보성이 강한 질문부터 인용되기 시작하고, 그다음 지역+업종 질문으로 확산되는 패턴을 보입니다. 조급하게 콘텐츠를 대량 생산하기보다 **사례를 꾸준히 쌓는 쪽**이 결과적으로 빠릅니다.
