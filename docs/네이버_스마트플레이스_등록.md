# 네이버 스마트플레이스 등록 — 입력값 시트

> **이 문서의 목적**: 등록 화면에 **그대로 복사해 넣는 것**입니다. 기억에 의존해
> 손으로 입력하면 반드시 어긋나고, 어긋나면 아래 「왜 글자 하나까지 맞춰야 하나」의
> 손해가 그대로 발생합니다.
>
> 값의 출처는 [`lib/site.ts`](../lib/site.ts) 한 곳입니다. 회사 정보가 바뀌면
> 그 파일을 고치고 이 문서도 함께 갱신하세요.

등록 주소: **https://smartplace.naver.com**

---

## 왜 글자 하나까지 맞춰야 하나

네이버는 «사이트에 적힌 업체»와 «플레이스에 등록된 업체»가 같은 곳인지를
**상호·주소·전화(NAP, Name-Address-Phone)** 세 값이 일치하는지로 판단합니다.

한 글자라도 다르면 — 예를 들어 사이트는 `주식회사 우앤주전력`인데 플레이스는
`우앤주전력`, 또는 사이트는 `053-525-0424`인데 플레이스는 `053)525-0424` —
**서로 다른 두 업체로 취급될 수 있습니다.** 그러면 사이트가 쌓은 신뢰도가
플레이스 순위에 반영되지 않고, 반대로 플레이스 리뷰도 사이트 검색에 도움이
되지 않습니다. 각각 절반의 힘으로 따로 싸우는 셈입니다.

지역 검색 결과의 최상단은 플레이스 영역입니다. **「대구 전기공사」로 검색하는
발주처가 가장 먼저 보는 자리가 여기**이므로, 이 등록 한 번이 사이트 전체보다
유입에 크게 작용할 수 있습니다.

## 1단계 — 먼저 확인할 것 (중요)

**신규 등록 전에 「미클레임 플레이스」가 있는지 반드시 확인하세요.**

네이버는 사업자등록 정보나 이용자 제보로 업체를 자동 생성해 두는 경우가 있습니다.
이미 그런 항목이 있는데 새로 등록하면 **같은 업체가 두 개**가 되어, 리뷰와 조회수가
갈리고 어느 쪽도 순위가 오르지 않습니다. 병합은 나중에 훨씬 번거롭습니다.

확인 방법 — 네이버에서 아래를 차례로 검색해 보세요.

```
우앤주전력
주식회사 우앤주전력
대구 서구 평리동 전기공사
```

- **이미 있으면** → 「내 업체가 맞다」 신청(업체 소유권 주장)으로 넘겨받습니다.
- **없으면** → 신규 등록. 신규 등록 업체는 초기 일정 기간 노출 가산이 있습니다.

## 3단계 — 등록 직후 해야 할 일

### ① 플레이스 URL을 알려주세요 — **코드에 반영해야 합니다**

등록이 끝나면 플레이스 주소가 `https://map.naver.com/p/entry/place/1234567890`
형태로 생깁니다. **이 URL을 알려주시면** [`lib/site.ts`](../lib/site.ts)의
`NAVER_PLACE_URL`에 넣습니다. 그러면 두 곳이 동시에 켜집니다.

- **연락처 섹션에 「네이버 플레이스」 버튼**이 나타납니다 (지금은 URL이 없어 숨김)
- **구조화 데이터의 `sameAs`**에 들어가, 검색엔진이 사이트와 플레이스를
  같은 업체로 묶는 근거가 됩니다

> 이 **양방향 링크가 NAP 일치만큼 중요합니다.** 사이트 → 플레이스, 플레이스 →
> 사이트가 서로를 가리켜야 «같은 업체»라는 신호가 완성됩니다. 플레이스 쪽
> 홈페이지 칸(위 2단계)이 그 반대 방향입니다.

### ② 사진 등록

플레이스는 사진이 있는 업체를 눈에 띄게 노출합니다. 지금 사이트도 실사진이 없어
[`TODO.md`](../TODO.md)에서 대기 중인 항목인데, **같은 사진을 양쪽에 쓰면 됩니다.**

촬영 우선순위 (사이트와 동일):

1. **배전반 설계·설치 3단계** — 외함 → 결선 → 완성품
2. 수전설비
3. 노후 분전반 교체 **전·후 같은 앵글**
4. 공장 내부 전경
5. 사업장 외관 1장 (플레이스 전용 — 찾아오는 사람 기준)

### ③ 리뷰 요청 동선 만들기

플레이스 순위에서 리뷰는 큰 비중입니다. 시공을 마친 고객에게 요청하세요.
문자로 보낼 문구를 준비해 두면 실행률이 올라갑니다.

```
안녕하세요, 우앤주전력입니다.
이번 공사 만족스러우셨다면 네이버 플레이스에 짧게 후기를 남겨주시면
큰 힘이 됩니다. 감사합니다.
→ (플레이스 링크)
```

> ⚠️ **대가를 제공하는 리뷰 유도는 하지 마세요.** 네이버 정책 위반이고
> 적발 시 노출이 제한됩니다. 사이트 구조화 데이터에도 별점을 넣지 않은 이유가
> 같습니다 — 실제 리뷰 없이 넣으면 정책 위반입니다.

## 값의 출처

이 문서의 모든 값은 [`lib/site.ts`](../lib/site.ts)에서 나옵니다.
회사 정보가 바뀌면 **그 파일을 먼저 고치세요** — 사이트 표시·구조화 데이터·
이 문서가 어긋나지 않게 하는 유일한 방법입니다.

| 값 | 상수 |
|---|---|
| 상호·대표자·주소·전화·번호류 | `COMPANY` |
| 영업시간 | `BUSINESS_HOURS` · `HOURS_TEXT` · `HOURS_NOTE` |
| 시공 가능 지역 | `SERVICE_AREAS` · `SERVICE_AREA_TEXT` |
| 외부 채널 URL | `NAVER_PLACE_URL` · `NAVER_BLOG_URL` · `KAKAO_CHANNEL_URL` |
