# 우앤주전력 홈페이지 관리자 사용법

> 개발자 없이 홈페이지 문구·사진·버튼을 바꾸고, 광고 성과를 확인하는 방법입니다.
> 주소: **https://www.wnjpower.com/admin**

---

## 0. 처음 한 번만 (설정)

### 0-1. 관리자 계정 만들기

1. [Supabase 대시보드](https://supabase.com/dashboard) → 프로젝트 `wnj-website`
2. 좌측 **Authentication → Users → Add user → Create new user**
   - 이메일: `wnj-2023@naver.com` (원하는 이메일이면 무엇이든 가능)
   - 비밀번호: 8자 이상
   - **Auto Confirm User** 체크 (이메일 인증 생략)
3. 좌측 **SQL Editor**에서 아래를 실행해 관리자 권한을 부여

```sql
insert into public.admins (user_id, email, name)
select id, email, '임태훈' from auth.users where email = 'wnj-2023@naver.com'
on conflict (user_id) do nothing;
```

> ⚠️ 3번을 하지 않으면 로그인은 되지만 **"관리자 권한이 없는 계정입니다"** 화면이 나옵니다.
> Supabase에 계정이 있다는 것과 이 사이트의 관리자라는 것은 별개입니다.

### 0-2. 데이터베이스 준비 (최초 1회)

Supabase **SQL Editor**에서 순서대로 실행합니다.

| 순서 | 파일 | 하는 일 |
|---|---|---|
| 1 | `supabase/schema.sql` | 견적문의 테이블 (이미 적용되어 있음) |
| 2 | `supabase/admin-schema.sql` | 관리자·콘텐츠·CTA·이벤트·게시판 테이블 |
| 3 | `supabase/analytics-functions.sql` | 실시간 분석 집계 함수 |

여러 번 실행해도 안전합니다.

## 1. 실시간 현황 — 광고가 돈값을 하는지 보기

**어드민 첫 화면**입니다. 15초마다 자동으로 새로고침됩니다.

### 무엇을 봐야 하나

가장 중요한 표는 **[유입 경로별 성과]** 입니다.

| 유입 경로 | 방문자 | 전화 | 문의 | 전환율 |
|---|---|---|---|---|
| 네이버 광고 `유료` | 120 | 4 | 2 | **5.0%** |
| 네이버 검색 | 80 | 5 | 3 | **10.0%** |
| 직접 유입 | 30 | 1 | 0 | 3.3% |

- **전환율** = (전화 클릭 + 견적문의) ÷ 방문자
- `유료` 배지가 붙은 줄이 **광고비가 나가는 경로**입니다.
- 광고의 전환율이 자연 검색보다 한참 낮으면 → 광고 문구나 랜딩이 잘못됐다는 신호입니다.
- 방문자가 100명이 안 되면 아직 판단하기 이릅니다. 숫자가 쌓일 때까지 기다리세요.

### 광고 링크에 표시를 남겨야 성과가 나뉩니다

광고를 등록할 때 도착 URL 뒤에 아래처럼 붙이면, 어느 광고에서 왔는지 자동으로 구분됩니다.

```
https://www.wnjpower.com/?utm_source=naver&utm_medium=cpc&utm_campaign=공장전기_3월
```

| 항목 | 넣을 값 | 뜻 |
|---|---|---|
| `utm_source` | `naver` / `google` / `instagram` | 어느 매체 |
| `utm_medium` | `cpc` (유료 광고일 때 반드시) | 광고인지 아닌지 |
| `utm_campaign` | 아무 이름 (예: `공장전기_3월`) | 어느 소재 |

> `utm_medium=cpc`가 빠지면 **유료 광고가 자연 검색으로 잡힙니다.** 이것만은 꼭 넣으세요.

### 광고를 클릭한 사람이 나중에 문의해도 잡힙니다

광고로 들어왔다가 며칠 뒤 주소를 직접 쳐서 문의해도, 그 문의는 **광고 성과로 기록**됩니다
(90일간 유지). 그래서 실제보다 광고 성과가 낮게 보이는 일이 없습니다.

## 2. 견적문의 — 놓치는 문의 없애기

- 아직 연락하지 않은 문의는 **파란 배경 + `신규` 배지**로 표시됩니다.
- 문의를 눌러 펼치면 **어느 광고에서 온 문의인지**까지 보입니다.
- **신규 → 연락함 → 견적 발송 → 수주 / 실패** 순으로 상태를 눌러 두세요.
  이 기록이 쌓이면 "어느 광고가 실제 수주까지 이어지는지" 알 수 있습니다.
- 메모란에 통화 내용을 적어두면 다음에 전화할 때 도움이 됩니다.
- 오른쪽 주황색 전화 버튼을 누르면 **폰에서 바로 전화가 걸립니다.**

## 3. 홈페이지 편집 — 문구·사진 바꾸기

### 기본 흐름

```
편집할 영역 선택 → 문구 수정 → (자동 저장) → 오른쪽 미리보기 확인 → [발행]
```

- 입력을 멈추면 **1.5초 뒤 자동으로 임시 저장**되고 오른쪽 미리보기가 갱신됩니다.
- **임시 저장은 방문자에게 보이지 않습니다.** 마음껏 고쳐보세요.
- 실제 사이트에 반영하려면 **[발행]** 버튼을 눌러야 합니다. 누르는 즉시 반영됩니다(재배포 불필요).
- 미리보기 위 📱 아이콘으로 **모바일 화면**을 확인할 수 있습니다.
  방문자의 대부분이 폰으로 보므로 꼭 확인하세요.

### 되돌리기

| 버튼 | 하는 일 |
|---|---|
| **수정 취소** | 편집 중이던 내용을 버리고, 현재 사이트에 올라간 상태로 되돌림 |
| **기본 문구로** | 처음 만들었을 때의 문구로 완전 초기화 |

### 편집할 수 있는 영역

| 영역 | 설명 |
|---|---|
| 상단 공지 배너 | 휴무·이벤트 안내. 평소엔 꺼두고 필요할 때만 켜세요 |
| 헤더 | 로고 옆 문구, 상단 띠, 메뉴 항목 |
| 히어로 (첫 화면) | **전환율에 가장 큰 영향.** 제목·설명·신뢰 지표 |
| 사업영역 | 3대 분야 카드 |
| 차별점·자격 | "믿을 수 있나"에 답하는 영역 |
| 진행 절차 | 문의부터 A/S까지 |
| 비용 안내 | 표준 작업 항목표. **단가가 정해지면 여기를 금액으로 바꾸세요** |
| 자주 묻는 질문 | 검색 결과에도 노출됩니다 |
| 견적 문의 폼 | 폼 주변 문구, 접수 완료 메시지 |
| 연락처 | 영업시간, 시공 가능 지역 |
| 푸터 | 맨 아래 회사 소개 |
| 검색엔진 노출 | 네이버·구글 검색 결과에 보이는 제목·설명 |

### 편집할 수 없는 것 (일부러 막아둔 것)

- **사업자등록번호·법인등록번호·전기공사업 등록번호·전화번호**
  → 실수로 바뀌면 조회가 어긋나 신뢰가 무너집니다. 바꿔야 하면 개발자에게 요청하세요.
- **사업영역 상세 페이지의 긴 기술 설명** (`/services/...`)

## 4. CTA 버튼 — 어떤 문구가 더 눌리는지 시험하기

### 문구만 바꾸기

1. **CTA 버튼** 메뉴 → 바꿀 자리에서 **[직접 설정]**
2. 문구·색·링크를 입력하고 **[저장]** → 사이트에 즉시 반영

### A/B 테스트 하기

1. 같은 자리에서 **[변형 추가]**
2. 이름을 `B`로 두고 다른 문구를 입력 (예: A = "무료 견적문의" / B = "3분 만에 견적받기")
3. 비중을 둘 다 `100`으로 두면 방문자에게 **반반씩** 보입니다
4. 며칠 뒤 **실시간 현황 → CTA 버튼 성과**에서 클릭률을 비교

> - 한 사람에게는 항상 같은 버튼이 보입니다. 새로고침해도 바뀌지 않습니다.
> - **노출이 변형당 100회는 넘어야** 판단할 수 있습니다. 그 전까지는 "판단하기 이릅니다"라고 표시됩니다.
> - 진 쪽을 지우고, 이긴 문구를 기준으로 다음 실험을 하세요.

### 링크 쓰는 법

| 목적 | 입력할 값 |
|---|---|
| 전화 걸기 | `tel:010-8552-9994` |
| 견적폼으로 이동 | `#quote` |
| 다른 페이지 | `/portfolio`, `/blog` |
| 외부 사이트 | `https://...` |

## 5. 게시판 — 검색으로 손님 오게 하기

### 왜 쓰나

"대구 공장 전기공사 비용" 같은 말을 검색하는 사람은 **이미 공사를 알아보는 중인 사람**입니다.
그 검색어로 우리 글이 뜨면 광고비 없이 문의가 들어옵니다.

### 쓰는 법

1. **게시판 → 새 글 쓰기**
2. **핵심 키워드**를 먼저 정합니다 (예: `대구 공장 전기공사 비용`)
   → 이 값을 기준으로 오른쪽 점검표가 계산됩니다
3. 글을 씁니다. 오른쪽 **SEO 점수**와 **점검 항목**이 실시간으로 바뀝니다
4. 빨강 ❌ 과 노랑 ⚠️ 항목을 고쳐 **80점 이상**을 만드세요
5. **[발행]** → 네이버·Bing에 자동으로 제출됩니다

### 글쓰기 요령

- **본문 1,500자 이상** — 짧은 글은 검색에서 밀립니다
- **소제목 2개 이상** — `## 소제목` 처럼 샵 두 개로 시작
- **첫 문단에 핵심 키워드** 넣기
- **사진에 설명 넣기** — `![대구 달서구 공장 배전반 설치](사진주소)`
- **내부 링크 1개 이상** — 예: `[배전반 설계·설치](/services/panel)`
- 검색 결과 제목은 **15~35자**, 설명은 **70~90자**

### 게시판 종류

| 종류 | 주소 | 용도 |
|---|---|---|
| 전기공사 정보 | `/blog` | 검색 유입용 글 (SEO 핵심) |
| 공지사항 | `/notice` | 휴무·안내 |
| 시공실적 | `/portfolio` | 현장 사진 올리기 |

> 메뉴에 블로그를 노출하려면 **홈페이지 편집 → 헤더 → "메뉴에 블로그 추가"**를 켜세요.

## 6. 검색엔진 — 자동 제출 확인

- 글을 발행하거나 홈 문구를 발행할 때마다 **네이버 서치어드바이저와 Bing에 자동 제출**됩니다.
- **구글은 즉시 제출이 불가능합니다.** 구글의 공식 즉시 색인 API는 채용공고·방송에만
  열려 있어 일반 페이지에는 쓸 수 없습니다. 대신 사이트맵의 수정 시각을 정확히
  유지하는 방식으로 되어 있고, 구글은 이를 보고 다시 방문합니다.
- **처음 한 번은 직접 등록해야 합니다:**
  - [네이버 서치어드바이저](https://searchadvisor.naver.com/) → 사이트 등록 → 사이트맵 `https://www.wnjpower.com/sitemap.xml` 제출
  - [구글 서치콘솔](https://search.google.com/search-console) → 소유 확인 → 사이트맵 제출

## 7. 자주 겪는 문제

| 증상 | 원인과 해결 |
|---|---|
| 로그인은 되는데 "권한이 없는 계정" | 0-1의 3번(SQL) 실행 안 함 |
| 실시간 현황이 "분석 기능이 준비되지 않았습니다" | 0-2의 2·3번 SQL 실행 안 함 |
| 고쳤는데 사이트에 안 보임 | **[발행]** 을 안 누름. 임시 저장은 방문자에게 안 보입니다 |
| 사진 업로드 실패 | 10MB 초과이거나 관리자 계정이 아님 |
| 미리보기가 실제 사이트와 다름 | 미리보기는 **발행 전 내용**을 보여줍니다. 정상입니다 |
| A/B 결과가 "판단하기 이릅니다" | 노출이 변형당 100회를 넘지 않음. 며칠 더 기다리세요 |

## 8. 폰에서 쓰기

어드민은 폰에서도 그대로 동작합니다. 특히 아래는 현장에서 자주 씁니다.

- **견적문의 확인 + 바로 전화** — 문의 목록의 주황 전화 버튼
- **공지 배너 켜기** — 갑자기 휴무가 생겼을 때
- **실시간 현황** — 광고를 켠 날 방문자가 실제로 들어오는지 확인
